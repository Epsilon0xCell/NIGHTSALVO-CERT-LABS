# Lab: Windows event log hunt

- Track: GIAC GSEC
- Objective mapping: Windows security and logging: account logon
  auditing, event ID fluency, account management events.

## Scenario

`events.csv` is an export of security events from one workstation,
WS-104, covering a single workday. The data is synthetic and shipped
as CSV on purpose: the skill being drilled is reading event IDs and
sequences, not parsing the EVTX binary format. Somewhere in a quiet
day of logons and logoffs, one account was taken over and used to
make a second account with privileges. Find the whole chain.

The file is generated by `gen_events.py` (seeded), and the copy in
this folder is the file it produces.

Event IDs you will need: 4624 (logon success), 4625 (logon failure),
4634 (logoff), 4720 (account created), 4732 (member added to a
security-enabled global group).

## Setup

Nothing to build. Any text tool, spreadsheet, or Python works.

## Tasks

1. Name the compromised account.
2. Name the internal source address the logon failures came from.
3. State how many failed logons (4625) that address produced.
4. Name the account that was created afterward.

## Answer format

Create `answers.txt` in this folder:

```
compromised_account=<account>
source_ip=<ip>
created_account=<account>
failure_count=<count>
```

Then run `python3 grade.py`.

## Hint ladder

1. Filter before you read. One event ID at a time turns 53 rows into
   four short stories.
2. Start with 4625 and group by source address. Then follow the same
   account forward in time: what happens right after the failures
   stop?
3. Microsoft's event ID documentation for 4625, 4720, and 4732
   describes exactly which fields carry the actor and the target.
